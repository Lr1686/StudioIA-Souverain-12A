## 2026-03-30 - CLI Feedback Alignment & Input Prompt Examples
**Learning:** For terminal-based CLI applications, adding concrete input examples (e.g., `(ex: Alice)`) directly within prompts and wrapping registration output in ASCII card delimiters significantly improves visual feedback clarity and reduces user ambiguity.
**Action:** Always include clear input format hints/examples in CLI prompt strings and align key-value outputs with horizontal dividers for structured readability.
